## Tanggung jawab minimum penanggung jawab modul

- Menulis deskripsi requirement, alur proses, dan acceptance criteria.
- Menetapkan struktur data dan migration yang dibutuhkan bersama tim.
- Menyepakati endpoint dan format response dengan backend/client.
- Mengimplementasikan UI web dan Android yang termasuk scope modul bersama kolaborator yang ditunjuk.
- Memastikan otorisasi dilakukan di backend.
- Menulis test untuk alur normal, validasi, error, dan role yang tidak berhak.
- Memperbarui dokumentasi, screenshot, dan status pekerjaan.

## Gate persetujuan modul

Modul dianggap siap diintegrasikan ketika requirement disetujui, kontrak API terdokumentasi, migration tersedia, akses diuji, UI menangani loading/error/empty state, dan pull request direview.
